# SEM1 OS — Engineering Semester 1 Tracker

A personal, browser-based study dashboard. No frameworks, no paid services, and no account required.

## Run it
1. Download `index.html`.
2. Open it in Chrome, Edge, or Firefox.
3. Add modules under each subject and track theory / numericals separately.

## Publish on GitHub Pages
1. Create a GitHub repository named `sem1-os` (or any name you like).
2. Upload `index.html` and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then Save.
6. Wait for GitHub Pages to publish the site.

## Features
- Six preloaded subjects and editable exam dates
- Add, rename, and delete subjects and unlimited modules
- Separate theory and numericals checkboxes
- Mark weak topics
- Daily task list
- Revision topic tracker
- Subject-wise progress analytics
- Export/import JSON backup
- LocalStorage autosave

## Important data note
Data is saved in the browser on the device where you use the site. GitHub Pages only hosts the website; it does not sync your progress between devices. Use **Export backup** regularly and **Import backup** on another device if needed. Clearing browser site data can erase your saved progress.
